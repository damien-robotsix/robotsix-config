Add `robotsix_config.history` — append-only version history for a component's own config file. Components now own their settings *and* their setting history: `apply_update()` performs the whole of `PUT /config` (deep-merge, preserve secrets the caller did not resubmit, validate before writing, record a version), `rollback()` restores an earlier version as a new one, and `mask_secrets()` masks before returning config over HTTP. Secrets are identified from the model's `SecretStr` fields rather than guessed from key names.
